# protocol/

This directory is reserved for the public interface material for sol pbc's transparency protocol: schemas, predicate/semantics documents, and conformance fixtures that let a third party build an independent verifier without relying on this repository's code.

Nothing is published here yet. This directory is deliberately created empty as part of the repository bootstrap so that its path can be named in [`.github/CODEOWNERS`](../.github/CODEOWNERS) and its own licensing terms can be stated in [`CONTRIBUTING.md`](../CONTRIBUTING.md) before any content lands, rather than after.

This is not a decision that content in this directory is, or will become, permissively licensed; it preserves the option without exercising it.
